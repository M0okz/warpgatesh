03 / Quiet by design

A small client.
A clear set of boundaries.

A few things to know.

Do I need WarpgateSH to use Warpgate?

No. Warpgate works with standard protocol clients. WarpgateSH is an optional, independent community client that keeps your authorized SSH targets available as local aliases. It is not affiliated with or endorsed by the Warpgate maintainers.

How do I install the Mac app?

Download the universal DMG from the latest release, drag WarpgateSH into Applications, and open it. macOS 13 or newer is required. The CLI can be installed from Preferences. See the macOS installation guide.

Does the app need to stay open?

No. A per-user background agent keeps your targets synchronized independently of the graphical companion. You can close its window and keep using your SSH tools.

Does my API token authenticate SSH connections?

No. Your personal API token is used to synchronize the targets available to your Warpgate user. SSH authentication remains separate and is handled by OpenSSH and your Warpgate instance.

What happens if synchronization fails?

Your last complete local snapshot stays in place, and its age remains visible. A failed sync does not replace valid aliases with an empty list. SSH connections still require network access to Warpgate and valid authorization.

Can I use it on Linux or Windows?

The Linux CLI and background agent are available as an early beta via Homebrew. The graphical companion currently targets macOS. Windows is not currently supported. See the Linux installation guide.
