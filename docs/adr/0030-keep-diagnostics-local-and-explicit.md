# Garder les diagnostics locaux et explicites

WarpgateSH ne collecte aucune télémétrie et n’envoie automatiquement aucun rapport de crash. Les journaux locaux tournants sont conservés sept jours sans Jeton d’accès, mot de passe, clé privée ni contenu de configuration SSH ; un diagnostic ne quitte le poste qu’après un export manuel que l’utilisateur peut relire avant partage.
