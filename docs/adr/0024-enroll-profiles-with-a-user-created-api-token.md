# Enrôler les profils avec un jeton API créé par l’utilisateur

L’ajout d’un Profil Warpgate ouvre l’Instance Warpgate dans le navigateur et guide l’Utilisateur humain vers la création de son propre Jeton d’accès. L’utilisateur colle ce jeton une seule fois dans la CLI ou le compagnon ; WarpgateSH le valide avant de le stocker dans le Trousseau macOS. Le client ne lit jamais les cookies du navigateur et ne recueille aucun mot de passe Warpgate.
