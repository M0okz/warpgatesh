# Détecter les capacités de l’API Warpgate

WarpgateSH décide de la compatibilité d’une Instance Warpgate en vérifiant les capacités et les champs d’API nécessaires, plutôt qu’en maintenant une liste rigide de versions autorisées. Une incompatibilité conserve l’Instantané local sans modifier SSH et décrit la capacité manquante avec la version détectée ; la version minimale officiellement prise en charge sera fixée après les essais du premier prototype.
