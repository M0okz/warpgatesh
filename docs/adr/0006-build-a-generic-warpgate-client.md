# Construire un client Warpgate générique

`warpgatesh` est un client utilisateur générique destiné à fonctionner avec toute instance Warpgate et à être publié sur GitHub pour la communauté. Homeblack sert de premier environnement de validation, mais ses URL, conventions de nommage, scripts Ansible et choix d’infrastructure ne sont jamais codés dans le produit.
