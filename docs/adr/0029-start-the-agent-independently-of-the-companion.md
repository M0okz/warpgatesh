# Démarrer l’agent indépendamment du compagnon

La création du premier Profil Warpgate enregistre l’Agent de synchronisation pour un démarrage automatique à chaque ouverture de session. Le Compagnon graphique ne démarre à la connexion que sur préférence explicite, et le quitter n’arrête jamais l’agent ; suspendre la synchronisation de fond nécessite une action distincte assortie d’un avertissement.
