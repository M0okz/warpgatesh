# CLI principale avec compagnon graphique facultatif

`warpgatesh` est d’abord une CLI capable de fonctionner seule, car l’accès SSH doit rester naturel depuis le terminal et portable de macOS à Linux. Une interface graphique facultative l’accompagne pour les préférences personnelles, l’état de connexion, la synchronisation automatique et la présentation, sans devenir nécessaire à une connexion SSH.
