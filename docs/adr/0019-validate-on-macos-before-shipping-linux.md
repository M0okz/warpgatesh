# Valider WarpgateSH sur macOS avant de livrer Linux

La première version publique complète cible uniquement macOS et doit être validée par un usage quotidien avant d’engager l’interface et le packaging Linux. Le cœur Rust et les tests CI restent portables dès le MVP, afin que Linux constitue une phase produit ultérieure plutôt qu’une réécriture, sans doubler prématurément la charge de QA et de distribution.
