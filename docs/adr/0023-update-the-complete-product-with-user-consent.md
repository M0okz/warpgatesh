# Mettre à jour le produit complet avec le consentement de l’utilisateur

WarpgateSH vérifie quotidiennement les nouvelles versions sans jamais les installer silencieusement. Une installation DMG peut appliquer, après confirmation humaine, une mise à jour Tauri signée qui remplace ensemble le compagnon, la CLI et l’agent ; une installation gérée par Homebrew signale la version disponible et délègue son application à `brew upgrade --cask warpgatesh`.
