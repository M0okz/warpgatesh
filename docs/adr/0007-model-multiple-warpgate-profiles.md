# Modéliser plusieurs profils Warpgate

Une installation de `warpgatesh` peut gérer simultanément plusieurs profils Warpgate, chacun reliant l’utilisateur à une instance avec son propre jeton et ses propres préférences. Ce modèle est présent dès le MVP afin d’éviter qu’un stockage initialement mono-instance ne doive être remplacé lorsque les utilisateurs combinent des instances personnelles, professionnelles ou de laboratoire.
