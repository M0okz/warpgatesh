# Native companion migration — 0.1.25

Validation performed on 1 November 2026. The baseline is signed v0.1.24; the
native architecture and Sparkle integration were reviewed at `f96481ae83f2fd0528f6347e7dbafce3dea3da78`.
This report distinguishes local fixtures, public artifacts and hardware coverage.

## Standards

The independent Standards review found no remaining actionable finding. The
custom-installer recovery findings were superseded by removing that installer.
The Nix bundle-check finding was fixed: packaging runs the bundle verifier and
DMG integrity check. Agent-owned writes, SSH isolation, Keychain namespaces,
explicit update consent and bundle identity remain intact.

## Spec

The independent Spec review found no remaining actionable finding in the pinned
implementation. Sparkle replaces the custom transaction/helper path, in line
with the user-approved ADR 0038. Legacy archive/manifest compatibility, separate
EdDSA signing, demo isolation and active-agent version restart were inspected.
This code review alone does not establish release delivery or Intel testing.

## Executed checks

- Nix workspace Rust tests, formatting and Clippy; Swift formatting and 19 tests.
- Native private-pipe contract: state schema, correlated failures, mandatory SSH
  approval, absence of fixture secrets in errors and clean EOF.
- Universal native app and DMG; four executables have arm64/x86_64 slices and
  macOS 13 deployment targets, with no Nix-store runtime references.
- A Developer ID signed private DEBUG fixture updated from 0.1.25 to 0.1.26 using
  Sparkle 2.10.1, a signed appcast and signed archive served only on localhost.
  The app was replaced and relaunched into isolated demo data. No real backend,
  profile, SSH configuration, token or LaunchAgent was changed by this fixture.
- An archive altered after signing was rejected by Sparkle before installation.
  The private app remained at 0.1.26 with its code signature valid. Dismissing the
  error returned the UI to an actionable state.
- Closing the updated fixture's window left it in menu-bar application mode;
  reopening restored foreground mode.
- Local release app and DMG signed with Developer ID, notarized and stapled;
  the extracted updater app also passed bundle and stapler validation.
- The actual release archive's Minisign signature was verified with the
  `minisign-verify 0.2.5` implementation used by the old updater.
- All fifteen documentation captures were refreshed in English from the running
  0.1.25 SwiftUI app with fictional demo data. Dimensions and hashes are recorded
  in `docs/assets/swiftui/manifest.json`.

## Limits and delivery tracking

The local machine is Apple Silicon. Universal slices and deployment metadata
are checked; this is not an execution test on Intel or macOS 13. Gregory has
another Mac for the public update test; its CPU and OS have not been established.
A real instance/SSO flow is not replayed destructively for this architecture
change; existing Rust API-contract and token-lifecycle tests remain in the suite.

The official 0.1.24-to-0.1.25 public update, final GitHub CI, Homebrew and deployed
website checks are recorded below as they complete. No unpublished artifact is
