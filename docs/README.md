# WarpgateSH documentation

WarpgateSH is a CLI-first macOS client that keeps the SSH targets available to
your Warpgate user synchronized with standard OpenSSH aliases.

- [Install WarpgateSH on macOS](installation.md)

The project [README](../README.md) remains the shortest introduction and command
reference. These guides provide the complete public onboarding path.
