WarpgateSH now runs as a fully native SwiftUI/AppKit macOS companion, with a standalone Rust backend and no Tauri runtime or web frontend.

- Native Sparkle updates handle signed downloads, installation permissions and relaunch. Installation still requires your approval; no automatic downloads or telemetry.
- Seamless migration from 0.1.24: the existing signed update archive and manifest remain compatible. Profiles, Keychain tokens, SSH aliases and background-agent choices are preserved.
- The menu bar companion, French/English interface, four appearance modes and desktop notifications remain available.
- Universal Apple Silicon/Intel app for macOS 13 or later. The CLI and background agent remain independent of the graphical companion.

The additional appcast.xml asset is the signed Sparkle feed. Existing 0.1.24 clients continue to use latest.json and the Minisign signature. WarpgateSH is an independent, unofficial community client.
