WarpgateSH 0.1.28 fixes a local engine error banner that could remain visible after the app recovered from a temporary interruption.

- The local engine error banner now clears automatically when the app successfully refreshes its state again.
- An outdated or cancelled refresh can no longer display an old error after a successful action.
- Errors from user actions remain visible so you can read and address them.

Signed and notarized universal app for Apple Silicon and Intel Macs running macOS 13 or later. Profiles, Keychain credentials and SSH aliases are preserved.
