WarpgateSH 0.1.27 makes direct VM commands easier to set up on a new Mac, with one command per VM in zsh completion.

- After installing the bundled `warpgatesh` command, the app offers to enable zsh integration. Choose **Enable zsh integration** to connect by typing a VM name directly, or **Later** to keep your shell configuration unchanged.
- Enable or disable the integration at any time in **Preferences → System → VM commands in zsh**. The app displays its current state and preserves your personal zsh settings.
- After enabling the integration, open a new terminal before using VM commands. Existing terminal sessions are not changed.
- Zsh completion shows one short command per VM from the default profile, such as `trust-admin-01`, without a duplicate `trust-admin-01.hblk` entry.
- Short commands connect through the profile-qualified SSH alias internally, so an existing personal SSH alias cannot redirect them. Personal shell commands keep priority; other profiles and shell-name conflicts use qualified commands.
- Qualified aliases remain available explicitly with `ssh` and `warpgatesh`.

Signed and notarized universal app for Apple Silicon and Intel Macs running macOS 13 or later. Profiles, Keychain credentials and SSH aliases are preserved.
